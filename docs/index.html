photos and videos.

MetaFix repairs date and time metadata in bulk. Load the files that came off a phone, a cloud service or an old backup with wrong or missing dates, see exactly what will change, then write it.

Nothing changes until you apply.

The main button previews first. A second press applies, and it names exactly which files it will write.

Every original is copied first.

Before a write, MetaFix copies each file into a BACKUPS folder beside it. Undo restores the last batch, names included.

Metadata only. No re-encoding.

ExifTool edits the date fields and leaves the image and video data alone. AVI files use an FFmpeg stream copy.

See every change
before it is written.

Shift by any amount, in either direction

A camera clock set a year behind and two hours ahead is one edit. Mix positive and negative values, and the sentence under the inputs says what will happen. Only the parts of each date that change are underlined.

Know where each date came from

The Read from column names the field each date was read from. Dates that exist only on the file system are flagged. Filter by a field to select exactly those files.

Undo the last batch

Undo copies each original back from BACKUPS, with its original filename and, on Windows, its created date.

Three edit modes

Set one date, copy one field into others, or shift dates by years to minutes.

Required preview

The main button previews first, then names the files it will apply to.

Before and after

Current and new dates sit side by side, with changed parts underlined.

Copy source hint

Copy mode picks the most common source field and shows a file count for each.

Selection-aware

Actions use the ticked files. With nothing ticked, they use every loaded file.

Drag and drop

Drop files or folders onto the window. Subfolder scanning is one checkbox.

Rename to timestamp

2019-06-14_18-30-00_photo.jpg, with (1), (2) for duplicates. Or drop the old name.

Clean backups

Lists tracked backups and asks before it deletes. Files it did not make stay.

Windows created date

Optionally sets the Date created that Windows Explorer shows, as well as the metadata.

Light and dark

The window follows your system appearance.

Quiet background tools

Reads and writes do not open terminal windows on Windows.

Set once

The ExifTool and FFmpeg paths are saved and remembered between sessions.

You also need ExifTool. MetaFix does not include it. On first launch, select Choose ExifTool and point it at the executable from exiftool.org. For AVI files, also set FFmpeg under Tools and keep ffprobe beside it.

Keep the app in a folder you can write to; it saves tool paths in data/config.json. Native media editing on macOS and Linux still needs more testing. To run from source with Python 3.10 or later, see the README.
